## Direct Node.js dependencies

- [bonjour-service](https://github.com/onlxltd/bonjour-service) 1.4.4: MIT (as declared in package metadata).
- [qrcode-terminal](https://github.com/gtanner/qrcode-terminal) 0.12.0: Apache License 2.0 (as declared in the upstream package's legacy licenses field). npm's current license display can omit this legacy metadata.

See package-lock.json for transitive dependencies. Verify all notices before distributing bundled binaries.

## Android / Kotlin Multiplatform dependencies

Android Gradle Plugin, Kotlin, JetBrains Compose, Ktor, kotlinx libraries, AndroidX, Google Code Scanner, and the Gradle wrapper have their own distribution licenses and notices. The app references them by dependency coordinates; it does not claim ownership. Validate their actual packaged contents and required notices before a binary release.
