# Community code of conduct

Muse Remote welcomes constructive collaboration by people of different backgrounds and skill levels. Be respectful, assume good intentions, and focus discussion on behavior, evidence and technical decisions.

Unacceptable behavior includes personal attacks, harassment, discrimination, threats, deliberately revealing private data, and repeated disruption of project discussions.

For ordinary contribution questions use GitHub issues. For conduct concerns contact the repository maintainer privately through their GitHub profile; for security issues use [private vulnerability reporting](SECURITY.md), **not** a public issue. Reports will be reviewed discreetly; abusive contributions may be moderated or removed.

The maintainer is responsible for fair enforcement and for documenting changes to these expectations.
